Регистрация в облачном сервисе GitHub (+)

- Из локального git репо - отправлять в облако

- Локальное связка с облачным репо

- Облачные репо:
-- создание
-- изменение файлов
-- ветвление
-- коммиты
-- клонирование облака в локальный репо

Репозиторий - это папка, за которой наблюдает git
локальный репозиторий - это папка на вашем компьютере
облачный репозиторий - это хранилище в облаке
облако - это чужой компьютер (где-то в интернет)

клиент - тот компьютер кто спрашивает
сервер - тот кто отвечает

мой компьютер может быть одновременно и клиентом и сервером,
и компьютеры в датацентре (сервер) они тоже клиенты
ntp сервера - компьютеры хранители времени

web сервер - это компьютер который настроен хранить сайты

Как инициализировать локальный репозиторий:
1. Создайте папку
2. В папке пишем git init

Как сохранить состояние (версию проекта):
1. Стейджинг Сообщаем git чтобы он взял все файлы и папки "git add ."
2. Сохраняем состояние файлов и папок внутри репо 
    "git commit -m 'Сообщение коммита'"
